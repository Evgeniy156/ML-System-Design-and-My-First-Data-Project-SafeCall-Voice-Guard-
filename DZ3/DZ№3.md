# ДЗ №3 — Бенчмаркинг продукта: SafeCall Voice Guard

> **Курс:** Машинное обучение (ИТМО)  
> **Тема:** Определение стандартов через анализ конкурентов  
> **Проект:** SafeCall Voice Guard — детекция голосовых дипфейков в телефонных звонках

---

## 1. Выбор конкурентов

### 1.1 Выбранные конкуренты

| # | Конкурент | Тип | Рынок | Метод защиты |
|---|-----------|-----|-------|-------------| 
| 1 | **Pindrop** (Pindrop Pulse) | Прямой | США, Enterprise | ML-анализ голоса (дипфейки) |
| 2 | **Hiya** (Hiya AI Phone) | Прямой/Косвенный | Глобальный, B2C | ML-анализ голоса + антиспам |
| 3 | **Kaspersky Who Calls** | Косвенный | Россия, B2C | База номеров + антиспам |

Дополнительно упоминаются как **альтернативы** (конкурируют за JTBD, но не детектируют дипфейки): МегаФон «Ева», Билайн «Защита от мошенников», банковские страховки, встроенная блокировка iOS/Android.

### 1.2 Обоснование выбора

**Pindrop** — прямой конкурент. Решает ту же задачу тем же способом (ML-анализ аудио в real-time). Единственное зрелое enterprise-решение с публичными метриками (99% accuracy, <1% FPR). Победитель FTC Voice Cloning Challenge 2024, $232M+ инвестиций. **Роль:** «золотой стандарт» для верхней границы бенчмарков.

**Hiya** — прямой/косвенный. Детекция дипфейков для B2C (совпадает с SafeCall). 500M+ пользователей через OEM (Samsung, AT&T). Основной бизнес — антиспам, детекция дипфейков — добавленная функция. **Роль:** эталон B2C-монетизации ($9.99/мес) + данные по проблемам точности.

**Kaspersky Who Calls** — косвенный. Решает ту же проблему (защита от мошенников), но другим способом (база номеров). Тот же рынок (Россия), та же ЦА. Блокирует 80–90% спама, но пропускает новые номера. **Роль:** конкурент за бюджет российского пользователя; его слабости = ниша SafeCall.

**Почему именно 3:** на российском рынке нет решений, анализирующих голос на дипфейки. Конкурентное поле: Pindrop + Hiya (прямые, зарубежные) + Kaspersky (косвенный, российский). Ни один не делает того, что SafeCall — **анализ голоса на дипфейки на русском языке для любого оператора**.

### 3.2 Ответы на ключевые вопросы

**Обязательные функции:**
1. Real-time детекция дипфейков — ядро продукта (Pindrop, Hiya)
2. Оповещение пользователя при угрозе (Hiya)
3. Работа на русском языке — ни Pindrop, ни Hiya этого не делают
4. FPR <10% — главная жалоба на Hiya
5. Простой интерфейс — фактор успеха Kaspersky

**Функции для отстройки:**
1. Анализ голоса на русском — уникально, нет ни у кого
2. UX для пожилых (крупный шрифт, автоматический режим, оповещение ребёнку)
3. Независимость от оператора (vs МегаФон «Ева» / Билайн)
4. Доступная цена 149–199₽/мес (vs $9.99/мес Hiya)

**Устранение недостатков конкурентов:**

| Недостаток | Решение SafeCall |
|-----------|-----------------|
| Pindrop: только Enterprise | B2C-продукт, 149₽/мес |
| Pindrop/Hiya: нет русского | RU-first, fine-tune на русскоязычных данных |
| Hiya: высокий FPR | Целевой FPR <10%, постоянная калибровка |
| Kaspersky: не анализирует голос | Ядро продукта — ML-анализ аудио |
| Kaspersky: пропускает новые номера | Анализирует голос, а не номер |

**Монетизация:** Freemium-подписка (как у Hiya и Kaspersky). Free: 5 проверок/мес. Premium: 149–199₽/мес — все звонки. Обоснование: Kaspersky ~93₽/мес — порог для РФ; SafeCall добавляет уникальную ценность → может стоить дороже.

**Улучшение UX:** автоматический режим (Kaspersky), простота для пожилых (ни у кого нет), прозрачность вердикта (confidence score), защита близких (МегаФон «Ева»).

## 4. Определение стандартов

### 4.1 Минимальные требования к функциональности

| Требование | Обоснование |
|------------|-------------|
| Бинарная классификация аудио (real/fake) | Ядро продукта — как у Pindrop и Hiya |
| Работа с русскоязычной речью | Целевой рынок — Россия |
| Оповещение при обнаружении дипфейка | Стандарт Hiya |
| Автоматический режим | Стандарт Kaspersky |
| Работа с телефонным аудио (AMR-NB, 8kHz) | Реальные условия |
| Логирование проверок | Улучшение модели |

### 4.2 Ключевые конкурентные преимущества

| Преимущество | Суть |
|-------------|------|
| **Единственное RU-решение** | Ни Pindrop, ни Hiya не работают на русском. Kaspersky не анализирует голос |
| **Анализ голоса, а не номера** | Новый номер мошенника — не проблема |
| **B2C по доступной цене** | Pindrop = тысячи $. SafeCall = 149₽/мес |
| **Фокус на пожилых** | UX для пожилых + управление от ребёнка |
| **Независимость от оператора** | Работает с любым оператором |

### 4.3 Модель ценообразования: Freemium-подписка

| Тариф | Цена | Включено |
|-------|------|----------|
| Free | 0₽ | 5 ручных проверок/мес |
| Premium | 149₽/мес | Автоанализ всех звонков, история, оповещения |
| Family | 249₽/мес | Premium + до 3 родственников + удалённое управление |

Обоснование: Kaspersky ~93₽ (без анализа голоса), Hiya ~900₽ (слишком дорого для РФ). SafeCall 149₽ — между ними, с уникальной ценностью.

### 4.4 Минимальные показатели (бенчмарки)

**Технические бенчмарки:**

| Метрика | Бенчмарк | Для пользователя | Обоснование |
|---------|:--------:|:-----------------:|-------------|
| **F1-score (RU)** | ≥ 0.85 | «85 из 100 верно» | ASVspoof ~0.97, Pindrop ~0.98, человек ~0.57. Среднее ≈ 0.84, +поправка RU |
| **Recall (fake)** | ≥ 0.90 | «9 из 10 пойманы» | Pindrop ~99%. Пропуск дипфейка = потеря денег |
| **FPR** | <10% | «<1 из 10 ложных» | Pindrop <1% (enterprise). Для MVP B2C до 10% допустимо |
| **Latency** | <2 сек | «Вердикт до конца звонка» | Pindrop/Hiya — real-time |
| **EER** | ≤15% | — | ASVspoof лучшие системы ~1–5% EER (чистый EN, студийное аудио). Деградация на телефонном канале (8kHz, AMR-NB) +5–7%, переход на RU (нет fine-tune данных) +3–5%. Итого: 1% + 7% + 5% ≈ 13%, с запасом → ≤15% |
| **Цена** | ≤199₽/мес | «Дешевле чашки кофе/день» | Kaspersky ~93₽. SafeCall выше (больше ценности) |

**UX-бенчмарки:**

| Метрика | Бенчмарк | Обоснование |
|---------|:--------:|-------------|
| **Время до первого вердикта** | ≤5 сек после начала звонка | Pindrop/Hiya — real-time. Для MVP допустима задержка, но вердикт должен прийти до конца звонка |
| **Шагов до настройки** | ≤3 (установка → разрешения → готово) | Kaspersky — «установил и забыл». Каждый лишний шаг = отток пожилых пользователей |

**Формула расчёта бенчмарка F1:**
```
Pindrop accuracy (EN):     ~0.99 → F1 ≈ 0.98
ASVspoof лучшие модели:    F1 ≈ 0.97
Человеческий baseline:     ~0.57

Среднее (0.98 + 0.97 + 0.57) / 3 ≈ 0.84
Поправка на RU + телефон → F1 ≥ 0.85 ✅
```

### 4.5 Проксиметрики (сравнение с Kaspersky)

Kaspersky Who Calls не имеет метрик детекции дипфейков — у него другой механизм (база номеров). Для корректного сравнения используем **проксиметрику** — общий показатель, на который влияют оба продукта разными способами.

**Проксиметрика: % предотвращённых мошеннических звонков**

| Показатель | Kaspersky Who Calls | SafeCall Voice Guard |
|-----------|:-------------------:|:--------------------:|
| Механизм | Блокировка по базе номеров | Анализ голоса (ML) |
| Покрытие известных номеров | ~80–90% (по отзывам пользователей) | Не применимо |
| Покрытие новых номеров | ~0% (нет в базе) | ≥85% (F1-score, анализ голоса) |
| Детекция дипфейков | 0% | ≥90% (Recall) |

**Бизнес-перевод:** По данным Сбербанка, ущерб от телефонного мошенничества в РФ — ~295 млрд руб./год (2024). Kaspersky блокирует звонки с известных номеров, но пропускает мошенников с новых SIM-карт и дипфейки. SafeCall закрывает именно этот gap — анализирует голос, а не номер. Совместное использование (Kaspersky + SafeCall) потенциально покрывает >95% угроз.

## 6. Итоговые выводы

**Стратегия отстройки:**
```
SafeCall = [Анализ голоса] ∩ [Русский язык] ∩ [B2C доступная цена]

Pindrop:   голос ✅  русский ❌  B2C ❌
Hiya:      голос ✅  русский ❌  B2C ✅
Kaspersky: голос ❌  русский ✅  B2C ✅
SafeCall:  голос ✅  русский ✅  B2C ✅  ← единственный
```

**Ключевые решения:**

| Решение | Обоснование |
|---------|-------------|
| Freemium-подписка | Работает у Kaspersky и Hiya; безопасность = рекуррентный доход |
| F1 ≥ 0.85 | Конкурентный ряд + академические бенчмарки |
| Recall (fake) ≥ 0.90 | Пропуск дипфейка разрушает доверие |
| Цена 149–249₽/мес | Выше Kaspersky, ниже Hiya |
| Русский язык — киллер-фича | Ни один конкурент не работает на русском |
| UX для пожилых | Уникальная незанятая ниша |

> **Главный результат:** Требования к SafeCall теперь **определённые и обоснованные** конкурентным анализом. Каждая метрика, цена и функция привязана к рыночным данным.
